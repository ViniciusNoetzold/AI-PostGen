# Requisitos Funcionais

### Essenciais (MVP)
1. [ ] Entrada de tema e tom de voz pelo usuário
2. [ ] Busca contextual no vault do cliente (RAG)
3. [ ] Geração de legenda, hashtags, menções e descrição top via IA
4. [ ] Preview editável pelo usuário
5. [ ] Notificação via Telegram quando sugestão pronta
6. [ ] Opção de agendar ou postar (modo seguro enquanto conta dev não aprovada)

### Desejáveis (Futuro)
- [ ] Geração de sugestões de imagem via IA
- [ ] Integração com calendário (Google/Apple)
- [ ] Analytics de desempenho pós-publicação
- [ ] Suporte a múltiplas plataformas (Twitter, LinkedIn)
